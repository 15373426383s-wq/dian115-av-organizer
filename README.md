# 番号整理插件

一个运行在网盘 / 媒体管理宿主（如 DIAN115）上的视频整理插件。它会自动识别文件名中的番号，从多个数据源刮削元数据（标题、演员、封面等），并按规则重命名、移动文件、生成 NFO 与 STRM。

---

## 它能做什么

- **自动识别**：扫描收件目录，自动从文件名中认出番号。
- **自动刮削**：按你设定的来源顺序，抓取标题、演员、封面、剧照等元数据。
- **自动整理**：按命名规则重命名文件、移动 / 复制 / 链接到目标目录，并生成 NFO、STRM 等配套文件。
- **多种整理模式**：刮削并整理、只整理不刮削、原地刮削，可随时切换。
- **实时 + 定时**：目录有变动立刻处理，空闲时也会定时兜底扫描，不会漏掉新文件。
- **番号订阅**：在 Telegram 机器人里发一个番号（例如 `av SSIS-001`），即可加入订阅并自动搜索整理。
- **演员资料**：可把演员信息同步到 Emby，方便在媒体库里按演员浏览。
- **AI 翻译**：可选接入 AI 提供商，对标题、标签等进行翻译。

---

## 安装

1. 在宿主的插件中心上传安装包（`.dian115p` 文件），ID 保持为 `local.av-organizer`。
2. 安装 / 更新都会保留你原来的设置和整理历史，无需重新配置。

> 需宿主支持插件 API 3.5 及以上（如较新版本的 DIAN115）。

---

## 配置

打开插件「设置」，按下面顺序填好即可。

### 1. 基本
- **工作模式**：选择「刮削并整理」（默认）、「只整理不刮削」或「原地刮削」。
- **收件目录**：放待整理文件的地方，支持多个目录（本地路径或云盘挂载）。
- **整理目标**：整理后的视频去哪里（本地目录，或 STRM 规则输出）。
- **失败目录**：认不出或整理出错的文件会被移到这里，方便你回头处理。

### 2. 刮削来源
- 勾选要用的数据源，并拖动调整先后**顺序**（前面优先）。
- 部分来源需要你填写 Cookie、代理或年龄验证状态才能正常访问。

### 3. 命名规则
- 设置生成后的文件名模板，例如 `{actor}/{number} - {title}`。
- 支持常用的条件、默认值、大小写、替换等变量写法，设置时可实时预览效果。

### 4. 识别与匹配
- **清理规则**：每行一条，用来去掉文件名里干扰识别的无关文字（支持前缀、正则、替换三类写法）。
- **模糊匹配**：当番号对不上时，会用更宽松的方式搜索，可调整匹配阈值。

### 5. 番号订阅（可选）
- 选择 115 账号、保存目录、下载器，以及要联动的站点。
- 之后就可以在 Telegram 里直接发番号让它自动下载整理。

### 6. 演员资料（可选）
- 选择 Emby 服务器与媒体库，开启后演员信息会同步过去。

### 7. 翻译与完整性（可选）
- 选择 AI 提供商和模型，开启翻译；翻译结果会自动缓存，避免重复消耗。

### 8. 文件管理
- 勾选「创建整理任务」，之后就能在「文件管理」页面手动勾选文件立即整理。

---

## 使用

**自动整理**：把文件丢进收件目录即可，插件会自动处理（监听触发 + 定时兜底）。

**手动整理**：在「文件管理」页面勾选文件，或点「立即整理」。

**番号订阅**：在 Telegram 机器人发送 `av 番号`，例如 `av SSIS-001`，插件会加入订阅并自动搜索整理。

插件提供多个页面方便查看与管理：概览、整理记录、待处理、识别测试、番号订阅、文件管理、演员资料、设置。

---

## 注意事项

- **站点访问**：部分数据源需要你自行通过年龄验证、配置 CookieCloud 或代理后才能正常刮削。
- **目录不要混用**：收件目录不要放在宿主自带的 TMDB 整理源目录里，以免两者互相干扰。
- **整理失败**：认不出番号或出错的文件会进入失败目录，插件会自动重试；长期处理不了的可在失败目录里手动处理。

---

## 常见问题

**Q：文件放进去没反应？**
检查收件目录是否填写正确、监听是否开启；也可在「文件管理」里手动触发一次整理。

**Q：刮削不到元数据？**
确认该来源是否已启用并排在前面；部分来源需要配置 Cookie / 代理 / 年龄验证。
