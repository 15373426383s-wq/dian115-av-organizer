# 1.3.0 页面与选择器验证

本轮使用现有宿主插件 API 3.5 文档，未修改宿主接口。页面、目录和账号交互使用模拟宿主验证，未向真实 115、PT、下载器或 Emby 发起写入。

## 变更

- 重写页面样式与导航：Liquid Glass 表面、宿主明暗主题、桌面侧栏、小屏横向导航、分区设置、文件管理和演员同步记录。
- 本地/CD2 文件列表与目录选择共用浏览器，支持面包屑、筛选、排序、多选、新建目录、加载和重试。
- 115 账号、目录、下载器、馒头站点、STRM 规则、Emby 服务器/媒体库、AI 提供商/模型使用选择器；资料来源排序、字段优先级和禁用规则使用共用选源控件。自定义查询协议、模板和规则仍可编辑。
- 切换 115 账号后清除旧目录；切换 Emby 服务器或 AI 提供商后清除依赖选项。读取失败或旧选项暂不可用时保留原值并显示说明。
- 目录编号使用字符串，远端名称完整显示。离线提交、回执去重和恢复核对共用账号规范化；不同账号的同一资源分别处理，响应账号或目录不符时进入核对流程。
- 清理重复的路径浏览与选项读取、来源排序代码，合并公共逻辑。未添加运行库、常驻服务或额外定时器。
- 清理项目说明中的历史功能比较，保留组件许可证及实际资料源地址。

- 自动测试 **318 项通过，0 失败，0 跳过**，包含原有识别、刮削、整理、订阅与演员测试。
